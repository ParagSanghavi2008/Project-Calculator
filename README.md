# CalcMate Calculator

A responsive calculator with a polished HTML interface, tactile circular keys, subtle click sounds, and a small Python command-line version.

## Open the web calculator

Open `index.html` in a modern browser. It works as a standalone page and needs no install or internet connection.

## Features

- Addition, subtraction, multiplication, and division
- Square root and cube root (including cube roots of negative numbers)
- Decimal input and chained calculations
- Responsive layout for phones, tablets, and laptops
- Touch-friendly buttons with press feedback and optional device vibration
- Keyboard input: digits, `+ - * /`, decimal point, Enter, Backspace, and Escape

## Python command-line version

```bash
python3 calculator.py
```

## Files

- `index.html` — complete web interface, styles, and calculator behavior
- `calculator.py` — command-line calculator
